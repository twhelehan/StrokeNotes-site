Welcome to StrokeNotes

StrokeNotes is a rowing coaching and outing log app designed to help coaches, coxes and crews record useful session information quickly and consistently.

The app is currently in beta testing. This means it is still being improved, and your feedback is very welcome. Please use it during real or test outings, try the different features, and let us know what works well, what is confusing, and what could be improved.

StrokeNotes is designed to help with:

  • Recording rowing outings
  • Logging coaching notes and session feedback
  • Capturing crew, boat and session details
  • Using a drill library to support coaching
  • Matching drills to faults or technical focus areas
  • Recording incidents and generating incident email reports
  • Importing telemetry data
  • Linking photos and videos to sessions
  • Keeping a searchable history of sessions
  • Building up useful people and boat records over time

Important beta note: StrokeNotes should not currently be relied on as the sole record for safety-critical incidents, safeguarding matters, or formal club records. Where required, please continue to follow your club’s official reporting processes.

1. App structure

StrokeNotes is organised into several main sections.

Sessions

This is the main outing log. Use this section to create, review and search rowing sessions.

Drills

This contains the drill library, including technical exercises that can be used during coaching sessions. You can browse drills and use filters to find suitable exercises.

Faults

This contains a list of common technical faults or focus areas. These are linked to drills so that coaches can search for exercises that address particular issues.

Incidents

This section is used to record incidents linked to rowing outings. It can help structure the information needed for safety follow-up.

Settings

This contains app information, beta notes, copyright/version details, support contact information, and links such as the privacy policy and website.

2. Creating a new session

To create a session, open the Sessions section and tap the add button.

A session can be used to record a normal outing, coaching session, race, technical session, or other water session.

The session form includes the key details needed to understand what happened during the outing.

Basic session details

You can record:

  • Date
  • Session type
  • Perspective
  • Location
  • Boat type
  • Boat name
  • Crew details
  • Cox or steersperson
  • Coach
  • Distance
  • Duration or time on water
  • Rating
  • Conditions
  • Notes and feedback

The app uses British rowing terminology where possible.

3. Choosing a session perspective

StrokeNotes allows sessions to be recorded from different perspectives. This is one of the most important features of the app because a coach, cox and crew member may all want to record slightly different information.

The available perspectives are:

Coach

Use this when you are coaching an outing. This perspective is intended for recording the structure of the session, what was worked on, what feedback was given, and what should be carried forward.

Cox

Use this when you are coxing a crew. This can be used to record the session from the cox’s point of view, including calls, steering, crew response, race pieces, technical focus and general observations.

Steersperson / crew

Use this when rowing in a coxless boat or recording the outing from within the crew. This is useful for bow-steered boats, small boats, or uncoached outings.

The selected perspective changes which fields are most relevant in the session form.

4. Boat and crew details

StrokeNotes supports structured boat and crew information.

Depending on the boat type selected, the app can show the correct number of crew seats.

Supported boat types include:

  • 8+
  • 8x+
  • 4+
  • 4-
  • 4x+
  • 4x-
  • 2-
  • 2x
  • 1x

For coxed boats, the app allows you to record the cox.

For coxless boats, the app allows you to record the steersperson where appropriate.

For example:

  • In an 8+ or 4+, the app records the cox.
  • In a 4- or 4x-, the app can record the bow steersperson.
  • In a 1x, there is only one athlete to record.

This helps keep outing records consistent and easier to search later.

5. People and boats

StrokeNotes includes a People and Boats library.

As you use the app, you can build up a list of commonly used people and boats. This makes future session entry quicker and more consistent.

The People library can be used for:

  • Athletes
  • Coxes
  • Coaches
  • Steerspeople

The Boats library can be used for club boats or regularly used private boats.

This helps avoid inconsistent spellings and makes it easier to filter or search sessions later.

6. Race sessions

When the session type is set to Race, StrokeNotes can show extra race-specific fields.

These may include:

  • Race name
  • Race result
  • Race-specific notes

These fields are only shown when relevant, keeping normal training sessions simpler.

Use this for head races, regattas, seat racing, private matches, or any outing where recording the race outcome is useful.

7. Adding notes and feedback

The notes fields are intended to capture the useful coaching or rowing information that might otherwise be forgotten after the outing.

Depending on the session perspective, you can record things such as:

  • What the session focused on
  • What went well
  • Technical feedback
  • Crew response
  • Areas to revisit
  • Focus for the next session
  • Coaching observations
  • Conditions or context that affected the outing

Good notes do not need to be long. A short, clear record is often more useful than a detailed essay.

Example:

Focused on catch timing and connection through the first half of the drive. Better rhythm by the second piece. Need to revisit blade preparation and posture into frontstops next session.

8. Drill library

StrokeNotes includes a built-in drill library.

The drill library is designed to help coaches and crews find suitable exercises for common technical aims.

Each drill may include information such as:

  • Drill name
  • Description
  • Coaching purpose
  • Suitable boat types
  • Suitable experience level
  • Rating suitability
  • Linked faults or focus areas
  • Notes on how to use the drill

The drill library can be used before, during or after an outing.

For example, a coach might use it to plan a session, or to find a drill that addresses a technical issue noticed on the water.

9. Drill Finder

The Drill Finder helps you narrow down the drill library.

You can search or filter drills based on the information available in the app.

This may include filters such as:

  • Technical fault or focus area
  • Boat type
  • Discipline
  • Experience level
  • Rating suitability

This is useful when you know what problem you want to solve but are not sure which drill to use.

Example uses:

  • Finding drills for early squaring
  • Finding exercises suitable for novice scullers
  • Finding drills that work in an eight
  • Finding low-rate technical drills
  • Finding drills for balance, timing or connection

The drill metadata is still being tested and refined, so feedback from coaches is especially useful here.

10. Faults library

The Faults section contains common rowing technical faults or coaching focus areas.

These are used to help organise the drill library.

A fault might relate to areas such as:

  • Balance
  • Blade placement
  • Catch timing
  • Drive sequencing
  • Finish position
  • Recovery control
  • Rating control
  • Steering
  • Rhythm
  • Connection
  • Posture

The idea is that a coach can identify a recurring issue and then use the linked drills to find possible exercises.

The Faults library is not intended to be a rigid coaching system. It is a practical tool to help organise technical information.

11. User-created drills

StrokeNotes allows user-created drills to be added.

This is useful if you have club-specific drills, coach-specific variations, or exercises that are not yet in the main library.

When creating a drill, try to include:

  • A clear drill name
  • A short description
  • The technical purpose
  • Any suitable boat types
  • Any relevant faults or focus areas
  • Any rating or experience guidance

User-created drills are useful during beta testing because they help identify what should be added to the main library in future versions.

12. Linking drills to sessions

Drills can be added to a session record.

This allows you to record what was actually used during an outing.

For example, a session might include:

  • Pick drill
  • Feet-out rowing
  • Pause at body-over
  • Roll-ups
  • Square-blade rowing

Adding drills to a session makes the outing history more useful because you can later review what was tried, what worked, and what should be repeated.

13. Incident reports

StrokeNotes includes an incident logging feature.

This is intended to help capture details of incidents that happen during or around an outing.

An incident record may include information such as:

  • Date
  • Session or outing link
  • People involved
  • Boat involved
  • Location
  • Description of what happened
  • Any immediate action taken
  • Notes for follow-up

The app can help prepare an incident email report.

Important: during beta testing, please do not rely on StrokeNotes as the only formal incident record. If your club, organisation or governing body requires a separate report, you should still complete that process.

For British Rowing incidents, users should also submit the required report through the official British Rowing incident reporting system:

https://incidentreporting.britishrowing.org

14. Telemetry

StrokeNotes supports telemetry data so that outing records can be linked to performance and GPS information.

Telemetry can be attached to a session to keep coaching notes, crew details and performance data together in one place.

Depending on the source, telemetry may include:

  • Distance
  • Time
  • Stroke rate
  • Pace or speed
  • GPS route
  • Heart rate
  • Split data
  • Stroke-by-stroke information

Telemetry is intended to complement coaching notes rather than replace them.

For example, telemetry might show that the crew maintained a consistent rate, while the coaching notes explain that rhythm improved after a particular drill.

Adding telemetry to a session

Telemetry can be imported and attached to a session record.

To add telemetry:

  1. Open or create a session.
  2. Select the telemetry option.
  3. Choose the file you want to import.
  4. Review the imported data.
  5. Save the session.

Once imported, the telemetry will be linked to that session.

Reviewing telemetry

Telemetry can be reviewed as part of the saved session record.

This may help with:

  • Comparing pieces within a session
  • Reviewing rating control
  • Looking at pacing and consistency
  • Supporting feedback to crews
  • Identifying where technical changes had an effect
  • Adding context to race or training notes

For example, after a race-preparation outing, the telemetry may help show whether a crew held the intended rate and pace across a piece.

Supported telemetry formats

StrokeNotes currently supports the following telemetry sources.

NK Devices

Telemetry can be imported from:

  • NK CoxBox
  • NK SpeedCoach

To import NK telemetry:

  1. Export a CSV file from the NK Link app.
  2. Save the exported file to your device.
  3. Import the CSV file into StrokeNotes.

CrewNerd

Telemetry can be imported from CrewNerd using exported TCX files.

To import CrewNerd telemetry:

  1. Export a TCX file from CrewNerd.
  2. Save the file to your device.
  3. Import the TCX file into StrokeNotes.

GPX Files

Generic GPX files can be imported from many GPS tracking applications and devices.

To import a GPX file:

  1. Export the GPX file from your tracking application.
  2. Save the file to your device.
  3. Import the GPX file into StrokeNotes.

Other TCX Files

TCX files from applications other than CrewNerd may also work when imported using the CrewNerd importer.

However:

  • These files are currently unsupported.
  • Results may vary depending on the application that created the file.
  • Some data fields may not import correctly.

If you encounter problems with a TCX file from another application, please report it during beta testing.

Telemetry beta notes

Telemetry support is still being refined.

During beta testing, please check that imported data appears sensible, particularly:

  • Distance
  • Time
  • Stroke rate
  • Pace
  • GPS route
  • Session association

Please report any telemetry that appears missing, incorrect or linked to the wrong session.

15. Media

StrokeNotes includes media support so that photos or videos can be linked to sessions, drills or coaching observations.

Media can be especially useful for technical coaching, because a short video often captures things that are difficult to describe in writing.

Depending on the feature available in the current beta version, media may include:

  • Photos
  • Short video clips
  • Coaching videos
  • Drill demonstration clips
  • Session-related images
  • Video linked to a specific outing or technical focus

Using media in a session

Media can be used to support a session record.

For example, you might attach or record:

  • A clip of the crew during a technical drill
  • A video of catch timing
  • A clip showing blade height or balance
  • A photo of conditions
  • A video from the launch
  • A short clip to review steering or race line
  • A drill demonstration for future reference

When media is linked to a session, it helps make the saved outing record more useful for later review.

Media and coaching feedback

Media is most useful when combined with clear notes.

For example, instead of simply saving a video, you might also add a note such as:

Video shows improved timing after the pause drill, but hands are still slow away at the finish. Revisit hands-away sequence next session.

This makes the media easier to understand later, especially if someone else reviews the session.

Media in the drill library

Media may also be used with drills.

This can help demonstrate:

  • How the drill should look
  • The purpose of the exercise
  • Common mistakes
  • The difference between good and poor execution
  • How the drill changes between boat types or experience levels

During beta testing, please let us know where a drill would benefit from a photo or video explanation.

Safe and appropriate use of media

Please only record media when it is safe and appropriate to do so.

Do not record video or take photos in a way that distracts from:

  • Steering
  • Coxing
  • Coaching
  • Navigation
  • Other river users
  • Crew safety
  • Launch driving
  • Situational awareness

Please also consider privacy and consent before recording or sharing media of other people.

This is especially important where videos include:

  • Juniors
  • Vulnerable people
  • Identifiable athletes
  • Incident footage
  • Private club facilities
  • Other river users
  • Coaching feedback that may be sensitive

Do not share media outside the app or club environment unless you have appropriate permission.

Media beta notes

During beta testing, media features may still be refined.

Please report any issues such as:

  • Photos or videos not saving correctly
  • Media appearing against the wrong session
  • Playback problems
  • Missing thumbnails
  • Poor upload/import behaviour
  • Videos that were available in an earlier build but no longer appear
  • Confusing permissions prompts
  • Problems using the camera in portrait or landscape orientation

If media is important to a session, please keep a backup outside the app during beta testing.

16. Email export and sharing

StrokeNotes includes email/export functionality for certain records.

This can be used to share session information or incident details.

Possible uses include:

  • Sending coaching notes to a crew
  • Sharing an outing summary with another coach
  • Sending an incident report to a safety officer
  • Keeping a copy of a session record outside the app

Before sending any exported information, please check the contents carefully, especially where personal information, incident details, telemetry, photos, videos or safety matters are involved.

17. Searching and reviewing sessions

The Sessions section can be used to review previous outings.

As more sessions are added, the app becomes more useful as a coaching and training history.

You can use session records to look back at:

  • Who rowed
  • Which boat was used
  • What the session focused on
  • Which drills were used
  • What feedback was given
  • What should be revisited
  • Whether any incidents were recorded
  • Whether telemetry was attached
  • Whether photos or videos were linked
  • Race outcomes
  • Patterns over time

This can be useful for coaches managing multiple athletes or crews, and for coxes or rowers trying to track progress.

18. Using StrokeNotes during an outing

The app can be used in different ways depending on preference.

Before the outing

You might use StrokeNotes to:

  • Plan the session focus
  • Check the drill library
  • Select drills for a particular fault or crew
  • Confirm boat and crew details
  • Prepare any telemetry files if you already have them
  • Check whether previous session notes are relevant

During the outing

You might use StrokeNotes to:

  • Make quick notes
  • Record drills used
  • Log an incident
  • Capture key observations before they are forgotten
  • Take a photo or video, where safe and appropriate

Only use the app when it is safe and appropriate to do so. Do not use your phone in a way that distracts from coaching, coxing, steering, navigation, crew safety or water awareness.

After the outing

You might use StrokeNotes to:

  • Complete the session record
  • Add coaching feedback
  • Record focus for next time
  • Import telemetry
  • Add photos or videos
  • Share notes with athletes or coaches
  • Send any required incident information

19. Beta testing guidance

As a beta tester, the most useful thing you can do is try the app in realistic scenarios and report anything that feels confusing, broken or missing.

Please test things such as:

  • Creating different types of sessions
  • Using different boat types
  • Adding crew, coxes, coaches and steerspeople
  • Searching previous sessions
  • Browsing the drill library
  • Using Drill Finder filters
  • Adding a user-created drill
  • Linking drills to sessions
  • Creating an incident record
  • Importing telemetry
  • Adding photos or videos
  • Trying the email/export features
  • Checking the Settings information and links

Useful feedback includes:

  • Anything that crashes or freezes
  • Fields that are unclear
  • Missing boat/session options
  • Incorrect rowing terminology
  • Drill metadata that feels wrong
  • Filters that do not produce useful results
  • Anything that takes too many taps
  • Anything that feels visually confusing
  • Telemetry that imports incorrectly
  • Telemetry that appears linked to the wrong session
  • Photos or videos that do not save or display correctly
  • Any information you expected to find but could not

When reporting feedback, please include:

  • What you were trying to do
  • What happened
  • What you expected to happen
  • Which device you were using, if known
  • Screenshots, if helpful

20. Privacy and data

StrokeNotes may contain personal information such as names, crew line-ups, coaching notes, incident details, photos, videos and telemetry data.

Please use sensible judgement when recording information about other people.

During beta testing:

  • Do not enter unnecessary sensitive personal information
  • Be careful when sharing exported notes, photos, videos or telemetry
  • Check emails before sending them
  • Follow your club’s data protection and safeguarding policies
  • Make sure you have appropriate permission before recording or sharing identifiable media
  • Take particular care with media involving juniors or vulnerable people
  • Do not use the app as the only formal record for serious incidents

The privacy policy is available at:

https://strokenotes.co.uk/privacy.html

21. Known beta limitations

StrokeNotes is still in development.

Current or expected beta limitations may include:

  • The user interface is still being refined
  • Drill metadata may need further review by coaches
  • Some filters may change in future versions
  • Incident reporting is not yet a replacement for formal governing body reporting
  • Telemetry import and display may still be refined
  • NK CSV, CrewNerd TCX and GPX imports are supported, but some files may require further compatibility improvements
  • TCX files from applications other than CrewNerd are currently unsupported
  • Telemetry data should be checked carefully during beta testing
  • Media capture, import and playback may still change
  • Photos or videos should be backed up outside the app if they are important
  • Sync, backup and sharing features may be added later
  • The app should not yet be treated as a final club record system

These limitations are normal at this stage of testing.

23. Quick start checklist

For a simple first test:

  1. Open StrokeNotes.
  2. Go to Sessions.
  3. Add a new session.
  4. Choose a session type and perspective.
  5. Select a boat type.
  6. Add the crew, cox, coach or steersperson.
  7. Add a few notes about the session.
  8. Add one or more drills.
  9. Import telemetry if available.
  10. Add a photo or video if useful and appropriate.
  11. Save the session.
  12. Check that the saved session appears correctly.
  13. Open the session and confirm that any telemetry or media has been attached correctly.
  14. Try searching or reviewing it later.
  15. Try the email/export features.
  16. Send feedback if anything feels wrong or unclear.

24. Thank you

Thank you for testing StrokeNotes.

The aim is to create a simple, useful rowing coaching and outing log app that feels practical for real club use — not just something that looks good in theory.

Your feedback will help shape what gets improved before a wider release.
